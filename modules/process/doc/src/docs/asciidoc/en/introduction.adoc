= Introduction

{organization} Workflow connects Mifos applications to workflow engines.
A Mifos application uses one set of operations for all engines.
The engine is a configuration choice. It does not change the code of the application.

Use these libraries when a Spring Boot application must run business processes in BPMN.
You get:

* Nine usecases that control an engine: deploy, delete, start, signal, terminate, list tasks, complete a task, history and replay.
* A REST API for the nine usecases.
* An adapter that lets a BPMN service task run a Mifos usecase or flow.
* Support for CIB seven and Flowable (in the application or remote), Operaton, Eximee and Camunda 8.

== Requirements

* Java 25 or later.
* Spring Boot 4.
* Gradle or Maven.
* For CIB seven, Operaton, Eximee and Flowable: a relational database, for example PostgreSQL.
* For Camunda 8: a Camunda 8 cluster.
